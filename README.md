# メディア表現入門演習Ⅱ 発表資料ページ

メディア表現学科1年次「メディア表現入門演習Ⅱ」の発表資料（PDF）を閲覧する Web ページです。

## 公開URL

- https://kwu-cms.github.io/cms-presentation/

## 年度構成

| 年度 | パス | 内容 |
|------|------|------|
| 2026（現行） | `/` | 5クラス×3グループの PDF 一覧・提出案内 |
| 2025（アーカイブ） | `/archive/2025/` | 前年度の発表資料・動画アーカイブ |

ヘッダーナビから年度を切り替えできます。

## 2026 の使い方（教員向け）

1. `js/index.js` の `SUBMIT_LINKS` にスプレッドシート／Teams の URL を設定
2. 各クラスに、スプレッドシートへのメタ情報記入と Teams への PDF 提出を依頼
3. 提出された PDF を `pdf/2026/[クラス]_group_[a|b|c].pdf` に配置（ダミーと差し替え）
4. `data/data_2026.csv` の `theme` などを更新

**注意:** PDF には学生名を記載しない（クラス・グループ・タイトルのみ）

## ファイル構成

```
├── index.html                 # 2026 メイン
├── archive/2025/              # 2025 アーカイブ
├── data/
│   ├── data_2026.csv          # 2026 データ
│   └── data_5classes.csv      # 2025 データ（変更しない）
├── pdf/
│   ├── *.pdf                  # 2025 資料
│   └── 2026/*.pdf             # 2026 資料（当面はダミー）
├── style/                     # 2026 スタイル
└── js/index.js                # 2026 スクリプト
```

## 制約

- HTML / CSS / JS の静的構成（フレームワークなし）
- GitHub Pages で動作
- `data/data_5classes.csv` など既存 2025 データはアーカイブ用に維持

## ライセンス

教育目的で使用されています。
