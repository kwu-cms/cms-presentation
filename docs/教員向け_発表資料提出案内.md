## 提出のしかた

スプレッドシートにメタ情報を記入し、PDF本体はTeamsフォルダへ提出してください。  
**PDFには学生名を記載しないでください。**

### 01 スプレッドシート雛形

次の列で **1行＝1グループ** として記入します。テーマが未定の場合は「（テーマ提出待ち）」のままで構いません。

| class | group | theme | pdf_filename | notes |
| --- | --- | --- | --- | --- |
| 高尾クラス | グループA | 発表タイトル | takawo_group_a.pdf | （任意） |
| 高尾クラス | グループB | 発表タイトル | takawo_group_b.pdf | （任意） |
| 高尾クラス | グループC | 発表タイトル | takawo_group_c.pdf | （任意） |

- クラス名は「水野 / 井口 / 高尾 / 八尾 / 山下」＋「クラス」
- グループ名は「グループA / B / C」（または 1班 / 2班 / 3班）
- `theme` には発表タイトルのみ（氏名は書かない）

雛形CSV：`data/spreadsheet_template_2026.csv`

### 02 PDFの提出先

発表資料PDFは、授業用Teamsの所定フォルダにアップロードしてください。

**提出先（Teams）**

`Teams ＞ メディア表現入門演習Ⅱ ＞ ファイル ＞ 発表資料PDF_2026`

※フォルダURLが確定したら、この文言のパス表記を差し替えてください。

- ファイル名：`[クラスローマ字]_group_[a/b/c].pdf`
- 例：`takawo_group_a.pdf` / `mizuno_group_b.pdf`
- PDF本文・表紙に学生名を入れない（クラス・グループ・タイトルのみ）
- 差し替え時は同名で上書きし、スプレッドシートの `theme` も更新
